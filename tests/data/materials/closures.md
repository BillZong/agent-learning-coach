# 闭包

闭包是函数连同它引用的外部变量的组合。闭包让函数可以携带自己的环境，不必依赖全局状态。

在 Python 里，返回内部函数时，外部函数的局部变量不会立刻消失——它被内部函数引用着，于是形成了闭包。

## 闭包与全局变量

用全局变量代替闭包会让函数的行为依赖程序状态，测试也就无从下手。闭包把依赖变成显式的参数，这是它真正的价值。

很多语言都支持闭包，只是叫法不同：JavaScript 叫闭包，Go 用返回值捕获，Rust 用生命周期标注。共同点是**函数记住了它出生时的环境**。

## 闭包什么时候会出错

闭包捕获的是**变量**而不是值。外部变量在闭包创建之后被重新赋值，闭包看到的是新值——这经常让人意外。

如果需要的是快照而不是活引用，就得在创建闭包时把值取出来传进去。
