# 内存与栈

栈是后进先出的数据结构，函数调用会把局部变量压栈，函数返回时弹栈。

堆是另一回事：它用于动态分配的对象，生命周期由程序显式管理。

递归太深就会撑爆栈——这是「递归必须收敛」的物理原因。

## 垃圾回收

Python 的垃圾回收是引用计数加上分代回收。引用计数立刻更新，分代回收处理循环引用。

## 内存与并发

多线程共享同一块内存时，一个线程写、另一个线程读，就可能出现「读到写了一半的值」。这就是竞态条件。

Python 的 GIL 让同一时刻只有一个线程执行字节码，因此纯 Python 代码里的竞态比别的语言少——但只要用了 C 扩展释放了 GIL，竞态就会回来。
