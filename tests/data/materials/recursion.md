# 递归

递归是函数调用自己来解决问题。递归需要一个终止条件，否则会一直展开直到栈溢出。

尾递归可以被优化成循环，因此在函数式语言里尾递归不会导致栈增长。

递归适合处理天然分层的问题：目录树、语法树、分形。

## 递归与栈

每次函数调用都会把局部变量压栈，函数返回时弹栈。因此递归的深度直接受栈的大小限制——Python 默认的递归深度限制是 1000 层。

斐波那契数列是递归的经典例子：F(n) = F(n-1) + F(n-2)。写成递归直观但慢，因为重复计算；写成循环加记忆化才实用。

## 递归的代价

递归的时间复杂度常常是指数级的，因为同一层的计算被重复做了很多遍。斐波那契数列就是典型：朴素递归要算 F(n) 次。

分治把问题拆成**互不重叠**的子问题，因此复杂度降到了 O(n log n) 这一类。排序算法大多如此。
